# Blog taslakları (İş 11) — onay bekliyor

Bu dosyalar **yayında değildir**; `blogContent*.mjs`'e bağlanmadı. Onayladıkların siteye eklenir, TR ve EN ayrı yazılır (çeviri değil).

| # | Taslak | Araç | Yayın engeli |
|---|---|---|---|
| 01 | UYAP'a TIF / TIFF evrak yükleme | Görsel → PDF | yok |
| 02 | Word dilekçeyi UDF'ye çevirme | Word → UDF | UYAP editöründe elle açma testi |
| 03 | E-başvuru PDF uyumluluk kontrolü | E-başvuru Uyumluluk | yok |
| 04 | Hazır dilekçe şablonları | Dilekçe Şablonları | şablon metinleri onayı (`HUKUKI_METINLER_ONAY.md`) |
| 05 | Kimlik ön-arka tek sayfa | Kimlik Tek Sayfa | gerçek fotoğrafla elle deneme |
| 06 | PDF'i Türkçe sesle dinleme | Sesli Okuma | Antalia ticari lisans teyidi |
| 07 | PDF'ten sınav sorusu üretme | Sınav Oluştur | yok |
| 08 | EPUB ↔ PDF | EPUB → PDF / PDF → EPUB | gerçek dosyalarla elle deneme |
| 09 | Markdown ↔ PDF | Markdown → PDF | yok |
| 10 | PDF'e üst/alt bilgi ekleme | Üst / Alt Bilgi Ekle | yok |

Kurallar: uydurma rakam yok; değişebilen kurum sınırlarında «ekrandaki açıklamayı esas alın»; gizlilik iddiası yalnızca cihazda çalışan araçlar için; sınav aracı sunucuda (yapay zekâ) çalıştığı için yazıda öyle anlatıldı.
