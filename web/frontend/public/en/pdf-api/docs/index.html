PDF Platform API Reference

This is the reference you keep open while wiring the API into your code. Authenticate with a Bearer key, call versioned routes under /v1, and read failures as RFC 9457 problem+json that includes a request_id you can quote to support. Rate-limit headers tell you how much headroom is left before a 429. Add an Idempotency-Key to a POST and a retried call after a dropped connection returns the first result instead of billing again. Retired routes announce themselves with Deprecation and Sunset headers well ahead of shutdown. If you generate clients from a spec, a machine-readable OpenAPI file is published alongside this page.

Frequently Asked Questions

How do I check that my key works without spending credits?

Call GET /v1/me with the key in an Authorization: Bearer header. It costs no credits, which makes it a good first request to confirm the key is accepted.

What does a failed request look like?

A JSON body of type application/problem+json (RFC 9457) with type, title, status, code, detail and request_id. Log the request_id; it is the fastest way to trace a specific failure.

How many calls can I make?

60 per minute for each key. RateLimit headers on every response show what is left, and going over returns 429 with a Retry-After value you can sleep on.

How do I avoid being charged twice after a timeout?

Send an idempotency key with the POST. If the connection drops and you repeat the call with the same key, the service returns the original result rather than starting new work.

How are documents submitted?

As a POST over HTTPS, either uploaded as multipart form data or referenced by a link the service can reach. Options travel as fields in that same request and the response is JSON.

What if my file is too big?

Size and page limits are set for each endpoint. Exceeding one yields a descriptive problem+json error. Splitting the document and sending the parts separately is the practical workaround.

Will an endpoint disappear without warning?

No. Breaking changes land in a new version. Before a route is retired its responses add RFC 9745 Deprecation and Sunset headers, with at least six months until it closes.

Is there a sandbox?

Keys belong to an account and each key's usage is tracked on its own, so create a dedicated key for development and watch its spend apart from production.
