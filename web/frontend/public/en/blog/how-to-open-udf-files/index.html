What Is a .udf File? Read UYAP Documents as PDF

UDF is a proprietary format used only by Turkey's court system, so Word, Preview and every PDF viewer ignore it. Here is how to read one in a minute.

Someone sent you a reasoned decision or a writ from UYAP. The file ends in .udf and nothing on your computer will open it. Word does not help, and double-clicking brings up the app picker. That is not your fault: UDF is a proprietary document format used only in Turkey.

What UDF is

UDF stands for UYAP Document Format. UYAP is Turkey's National Judiciary Informatics System, run by the Ministry of Justice, and petitions, writs, procedural orders and reasoned decisions are all downloaded with this extension.

The format is built to preserve a document's integrity and the electronic signature on it. That is sound design, but in practice a document that leaves the system becomes unreadable for the other side, so the UDF you send a client will not open on their computer.

The official route and its catches

The official answer is the Ministry's free UYAP Document Editor, which opens the file and offers save as PDF. It works, but it does not suit every situation:

  • It requires an installation and may need Java on your machine.
  • Whoever you send the document to needs the same program, which is rarely realistic to expect of a client.
  • On someone else's computer, or on a phone, you cannot install anything.

The install-free route

A UDF file is really an archive carrying the document's text and formatting. That structure can be decoded and redrawn, so the file can be turned into a PDF right in the browser with nothing installed. The UDF tool on PDF Platform does this on your device, which matters because court documents carry party names, identity numbers and case details. The file is never sent to a server.

The PDF is a copy, not the signed original

This distinction is worth underlining. The electronic signature in a UDF belongs to the document as it exists in that file. Convert it and you hold a readable copy, but the signature itself does not carry over.

For reading, archiving, sending to a client or consulting a colleague, the PDF is perfectly fine. For an official filing, keep using the signed UDF original.

Other common UDF problems

  • The file looks corrupt: the download may have been cut short, so download it again from UYAP.
  • The file is too large to upload: usually because of images pasted into it, which you can upload as separate exhibits.
  • It will not open on a phone: UYAP has a mobile editor app, but converting to PDF works on any device.
  • The recipient cannot open it: send a PDF, not a UDF. As a rule, any document leaving the system should be a PDF.

Editing the text in Word

There are two routes. The quick one is to copy the .txt text the tool gives you and paste it. To keep the formatting as well, convert to PDF first and then convert the PDF to Word.

Frequently Asked Questions

What is a UDF file?

UDF (UYAP Document Format) is the document format used by Turkey's national judiciary system. Petitions, writs, procedural orders and reasoned decisions are downloaded with this extension.

Can I open a UDF file with Word?

No. Word does not recognise the format. Convert it to PDF first, and then to Word if you need to edit the text.

Is there a way to open UDF without installing software?

Yes. You can convert a UDF to PDF in your browser. No UYAP Document Editor or Java installation is needed, and the work happens on your device.

Is the electronic signature preserved in the PDF?

No. The output is a readable copy and does not carry the electronic signature held in the UDF. Use the signed UDF original for official filings.

Is my document safe?

Conversion happens entirely in your browser and the file is never sent to a server. Court documents carry personal data, so this tool deliberately keeps the work on your machine.

Can I convert several UDF files at once?

Yes. You can add up to 20 files. One file downloads as a PDF, and several download together in a ZIP.
