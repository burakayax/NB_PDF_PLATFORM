Assembling a Tender Bid PDF: Order, Numbers, Signatures

In a tender, how the file is organised is the first thing the committee sees. A bid they can navigate quickly starts ahead of one they cannot.

A tender bid is as much about organisation as about documents. A committee works through dozens of files in turn, and the one where things are easy to find has an advantage. Most authorities now want bids electronically, which leaves presenting them together, in order and legibly entirely to you.

The specification always wins

Nothing here overrides the instruction in the authority's own specification. If it states the order of documents, the file format, the naming or a size limit, follow it to the letter. Failing a formal requirement can be enough on its own to have a bid excluded.

The fastest approach is to download the specification and search it for file, format, PDF, signature and size, noting every clause that comes up.

Order the documents as the specification lists them

Tender specifications give the required documents as a numbered list. Build your file in exactly that order. A committee member works with the list in hand, and a file that follows the same sequence makes the review flow.

  1. Prepare each document as a PDF: Download anything from official portals directly as a PDF, and scan the paper documents.
  2. Arrange in specification order: In the merge tool, drag the files to match the numbering on the list.
  3. Combine into one file: The work happens in your browser, and your bid is not uploaded to a server.
  4. Add page numbers: With a numbered file, the committee can ask which page a document is on, and you can answer.

Why page numbers help

In a hundred-page bid, page numbers make a table of contents possible. A contents page at the front, listing where each document begins, makes the committee's job markedly easier and makes your file look like careful work. Most competitors will not bother.

Size limits against scan quality

Electronic tender systems impose size limits, yet documents also have to be legible, because an unreadable document counts as a missing one. You have to balance the two.

  • Scan in greyscale at 300 DPI. If colour is not needed, do not use it, because it multiplies the file.
  • If there is a company stamp or a coloured signature, scan only those pages in colour and leave the rest grey.
  • After compressing, always check whether the stamp is readable, the signature is sharp and the smallest type is still legible.
  • If you are still over the limit, splitting the file is safer than lowering quality.

Never crush the whole file at maximum compression. An unreadable stamp in a tender file can lose work you had already won. Look at which pages are heavy first, since the problem is usually in a handful of them.

Signatures need care

Signatures are critical in bids, and authorities generally require a wet signature or a qualified electronic signature. Placing an image of a signature on a PDF meets neither requirement, because it is only a picture.

In practice the right route is to print, sign by hand and scan, or to use the electronic signature infrastructure the authority accepts. Image signatures suit informal situations such as internal correspondence and draft sharing.

A last check before you submit

  • Is every item on the specification's list present in the file?
  • Does the order match the specification?
  • Are time-limited documents such as registration and tax-clearance certificates current?
  • Is every page upright and legible?
  • Does the file name match what the authority asked for?
  • How many hours are left before the deadline? Do not leave the upload to the last hour, because system load is a real risk.

Frequently Asked Questions

Should a tender bid be a single PDF?

It depends on the authority's specification. Whatever it says about format, naming and the number of files must be followed to the letter, since failing a formal requirement can get a bid excluded.

In what order should the documents go?

In the order of the numbered list in the specification. The committee works with that list in hand, so a file following the same sequence makes each document easy to find.

If the file exceeds the size limit, should I lower quality?

Look first at which pages are heavy, because usually a handful of scanned pages are responsible. Splitting the file is safer than sacrificing the legibility of stamps and signatures.

Is adding a signature image to a PDF enough?

No. An image signature is only a picture and does not stand in for a wet signature or a qualified electronic signature. Use the method the authority accepts.

Do I need page numbers?

Not unless the specification asks for them, but they help in large files. They make a table of contents possible and let the committee find a document quickly.
