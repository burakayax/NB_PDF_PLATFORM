Excel to PDF Without Split Columns: Print Setup Tips

What the PDF looks like is decided by the print settings in your workbook. Two minutes of setup separates a clean quote from a scatter of columns.

Send an Excel file as it is and columns often shift, pages split and the print area breaks on the other end. A PDF looks identical for everyone, as long as the workbook is set up properly first.

Why convert

  • It locks the layout, so cells, column widths and page breaks look the same everywhere.
  • It is print-ready, and print-area and fit-to-page problems disappear.
  • It cannot be changed by accident, which suits report, quote and invoice tables.
  • It opens on devices without Excel installed.

Three steps

  1. Upload the Excel file: Add your .xls, .xlsx, .ods or .csv file to the Excel to PDF tool.
  2. Convert: The file is processed on the server and turned into a PDF with tables, cells and formatting preserved.
  3. Preview and download: Check the result and download the PDF, ready to share and print.

Set the print options first

A wide table converted without print settings comes out with columns scattered across pages and is unreadable. A couple of minutes of setup completely changes how usable the output is.

  • Set the orientation to landscape; with many columns this is almost always needed.
  • Define the print area to stop empty cells spreading across pages.
  • Use the option to fit all columns on one page.
  • Set the header row to repeat on every page, which decides readability on multi-page tables.
  • Decide whether gridlines should print.

For wide tables with many columns, landscape orientation and an adjusted print area in Excel before converting keep everything on the page and readable.

Workbooks with several sheets

An Excel file usually holds several worksheets, and not all need sharing. If working calculations, raw data or old period tabs end up in the output, the document bloats and may carry information that was never meant to leave. Decide which sheets go into the output before converting, rather than deleting pages afterwards.

Hidden information

Excel files carry more than they show: hidden rows and columns, data concealed by filters, cell notes and other sheets that formulas point at. Hidden rows usually stay out of the PDF, but cell notes and filtered data can appear unexpectedly. Review everything hidden before converting a table that is going outside.

Quotes and invoices

The real reason to convert a quote or invoice prepared in Excel is to create a fixed document whose figures the recipient cannot change. Two extra steps help: page numbers show completeness on multi-page quotes, and a permissions password restricts copying and editing.

Before you send it

  • Do page breaks fall in sensible places, or is a line item split in half?
  • Do amounts and currency display correctly?
  • Is the smallest type readable, especially if it will be printed?
  • Is there a note or column left in that you did not want shown?

Frequently Asked Questions

Do formulas show in the PDF?

They do not. The PDF carries the result of a formula. If you want to show how a figure was calculated, add it as a separate explanatory line.

Can a CSV file be converted?

Yes, .csv files are supported. Since CSV carries no formatting the output is plain; for a tidier look, format it in Excel first.

Do charts come across into the PDF?

Charts on the worksheet are included if they fall inside the print area. If a chart is on its own sheet, that sheet has to be part of the output too.

What if a very wide table will not fit on one page?

If landscape and fit-to-page are not enough, splitting the table into sensible column groups preserves readability. Squeezing it onto one page at tiny type produces output nobody can read.

Will converting Excel to PDF break the table?

No. Cells, column layout and formatting are preserved. For wide tables, landscape orientation and a set print area give the best result.

Which file types can I upload?

You can upload common spreadsheet formats such as .xls, .xlsx, .ods and .csv and convert them to PDF.

Can I get the table back into Excel?

Yes. Use the PDF to Excel tool to export tables from the PDF into an editable .xlsx file.
