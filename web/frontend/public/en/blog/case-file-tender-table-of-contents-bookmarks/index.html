Clickable Table of Contents for Case Files and Tenders

In a multi-part file the reader must reach the right section in seconds. How to add a contents page and bookmarks while merging.

A case file, a tender bid, an accounting folder, thesis appendices: they all share a problem. Dozens of documents end up in one file and the reader cannot tell which page holds the annex they need. The fix is to add a contents page and bookmarks while you merge.

What you get

  • One PDF with your files merged in the order you pick
  • A contents page at the front listing each section and its starting page
  • A click on any line jumps to that section's first page
  • Bookmarks in the PDF reader's side panel
  • Optional: a Page 3 / 42 footer on every page and a Back to contents link at the start of each section

Step by step

  1. Add the files: Choose 2 to 20 PDFs, up to 50 MB each. Every file becomes a card with a thumbnail and its page count.
  2. Put them in order: Drag the cards or move them with the arrows; use Sort A-Z to order by name.
  3. Edit the titles: The default title is the file name with underscores and dashes turned into spaces. Write something meaningful to the reader, such as Annex 1 Lease Agreement.
  4. Choose the settings: Set the heading, numbering, footer and back link, and change the output file name.
  5. Merge and download: If the contents run long they continue onto the next page automatically, and section page numbers are calculated to match.

Merge + Table of Contents — Merge PDFs and add a clickable contents page and bookmarks; your files never leave your device.

Writing titles that work

File names are often written for computers: scan_0047. A contents page is for a person. Use short titles that say what the item is, like Annex 3 Bank guarantee letter. Very long titles are cut to two lines at most, so put the main idea first.

When page sizes are mixed

A4, Letter and landscape pages keep their own size, while the contents page is added as portrait A4. The annexes are not altered; one uniform contents page simply appears at the front.

Protected or damaged files

A password-protected PDF cannot be handled in the browser, and the tool tells you exactly which file it is. Remove the password and add it again. A file that cannot be read does not block the others; its card is flagged and it is left out of the merge.

A court or an agency may have its own format requirements. If so, check the notice or guidance before you send the file.

Frequently Asked Questions

What is the minimum number of files?

Because it merges, you need at least 2 valid PDFs.

What if the contents are longer than a page?

The list continues onto the next page automatically and the section page numbers are calculated accordingly.

Do bookmarks show in every PDF reader?

Bookmarks are a standard PDF feature; most readers show them in a side panel.

Do my files get uploaded?

No. Merging and building the contents page happen in your browser.

Is the page footer required?

No, it is optional. If you turn it on, every page gets Page 3 / 42.
