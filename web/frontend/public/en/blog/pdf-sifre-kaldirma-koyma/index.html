Remove a PDF Password and Add a Password to a PDF

Tired of a PDF asking for a password every time, or want to protect a sensitive document? Both take just a few steps. Here's the right way.

There are two different needs around PDF passwords: permanently removing a password you know, or adding a password to protect a document. You can do both with separate tools.

Removing a password (unlocking)

If a PDF keeps asking for a password and you want to use it without typing one each time, the Unlock PDF tool can remove the password permanently. You need to know the document's password.

  1. Upload the PDF: Add your password-protected document to the Unlock PDF tool.
  2. Enter the password: Enter the document's current password — only for documents you're authorized to.
  3. Download the unlocked file: The tool removes the password; no more prompt on each open.

Unlock PDF — Remove a password you know and use the PDF freely.

Adding a password (protection)

The opposite: to protect a sensitive contract, medical report or financial document when sharing, the Encrypt tool lets you add an open password to a PDF, so only those who know it can open the file.

Encrypt PDF — Add an open password to your sensitive document.

Only remove passwords from documents you own or are explicitly authorized to.

Frequently Asked Questions

How do I remove a PDF password?

Upload the document to Unlock PDF, enter the current password and download the unlocked version. You need to know the password.

How do I add a password to a PDF?

Upload the document to the Encrypt tool and set an open password; only those who know it can open the file.

Can I open a PDF whose password I don't know?

No. These tools are only for documents you're authorized to and whose password you know.
