Sending Your CV as a PDF: Format, Name and ATS Checks

Your CV is often read by software before a person sees it. A PDF with real text, a clean layout and a sensible name gets through that first step.

A CV is the first document an employer sees about you, and a résumé built in Word can shift on other computers or change its fonts. The fix is simple: convert it to PDF before sending. The details below decide whether it is also read correctly by the software many employers use.

Why PDF

  • It looks the same on every device, with fonts, line spacing and layout preserved whoever opens it.
  • It is the professional standard, and most employers and career portals prefer or even require it.
  • It will not change by accident, whereas a Word file can shift when opened.

How application systems read your CV

At many large employers and career portals your CV is read by software first, and reaching a person depends on that. These systems parse the text in the document, so your PDF must contain real text. A CV exported as an image from a design tool, or built from a screenshot, is a blank page to the system. Test it by opening the PDF and trying to select your name with the cursor. If you cannot, it is an image.

Layouts that make automatic reading harder

  • Two-column designs, where reading order can scramble and details run together.
  • Burying information in text boxes or tables.
  • Putting contact details in the page header, since some systems never read headers.
  • Showing skill levels only as bars or stars, because information with no text equivalent is not recorded.
  • Unusual section headings; a creative title instead of Experience makes matching harder.

Clean up before converting

A PDF freezes the Word document as it stands, so turn off track changes, accept all revisions and delete comments first, or those traces can end up in the output. Check the author name in the document properties too. If you took the template from someone else, another name may still be sitting there.

File name and sending

A recruiter downloads dozens of files a day, and a document called cv_final_v3.pdf gets lost in the folder. A name in the form First_Last_CV is easier to find and looks considered. When a cover letter and certificates are requested, merging them into one PDF is tidier than separate attachments, and page numbers show the document arrived complete.

If you are asked to send several documents (CV, cover letter and certificates) as one file, convert them to PDF and then combine them with Merge PDF.

A last look before sending

  • Do fonts and alignment look the same as in Word?
  • Are links such as LinkedIn and your portfolio clickable and pointing at the right address?
  • Is the file size reasonable? Compress it if a photo inflated it.
  • Is there an old employer name or a draft note left in that you did not want shown?
  • Open it on a phone once, because many recruiters take their first look there.

Frequently Asked Questions

How long should a CV be?

The common expectation is one page for a few years of experience and two for longer careers. Bringing relevant experience forward beats adding material to fill a page.

Should I send PDF or Word?

Unless the posting says otherwise, send PDF so the layout holds on every device. Some systems explicitly ask for Word, in which case follow the instruction.

Should I include a photo?

Expectations differ by country and sector, and there is no single rule. If you include one, keep it small enough not to inflate the file.

Should I password-protect my PDF?

No. A password-protected CV cannot be opened by an application system and can get you screened out.

Does converting a Word CV to PDF break the formatting?

No. The Word to PDF tool preserves fonts, tables and layout, so your CV looks the same on every device.

Is converting a CV to PDF free?

Yes. Upload your Word document and create and download the PDF instantly.

What should I name the file?

Use a clear name such as First_Last_CV.pdf. Employers find it professional and can locate your file easily.

Can I combine my CV and cover letter into one PDF?

Yes. After converting both to PDF, combine them into one document with the Merge PDF tool.
