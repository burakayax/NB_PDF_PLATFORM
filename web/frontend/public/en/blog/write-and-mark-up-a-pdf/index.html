Mark Up a PDF: Highlight, Draw and Add Notes

Reviewing a document, you want a pen in your hand. Markup adds highlights, drawings and notes on top of the page and leaves the original text exactly as it was.

Reviewing a contract, an assignment or a report, you want to highlight the key sentence, jot a note, box a clause or point with an arrow. Markup PDF lets you do exactly that in the browser, and your file never leaves your device.

The tools

  • Highlighter: paints over text semi-transparently, so the text below stays readable.
  • Pen: freehand drawing, with a straight-line mode as well.
  • Box and Arrow: frame a region or point to it.
  • Text: write a note in the margin or on the document.

Four steps

  1. Open the PDF: Drag and drop or choose the document you want to mark up.
  2. Pick a tool and colour: Highlighter, pen, box, arrow or text, then a colour and thickness.
  3. Draw on the page: Drag to mark. Marker and pen offer a Straight mode for drawing cleanly over lines of text.
  4. Edit and download: Use Select to move, resize or recolour a mark, and undo with Ctrl+Z. Then click Apply and download.

Marks are added on top of the document. Existing text is never removed or changed, and highlighter and pen are semi-transparent so the text below stays readable.

Markup, editing and redaction are different

The three look alike, yet the results differ completely, and picking the wrong one causes problems.

  • Markup adds a layer over the document. The text underneath stays readable and searchable, which makes it right for review and feedback.
  • Editing actually changes the text in the document. This is what you need to correct a wrong date or amount.
  • Redaction removes the text from the document. It is the only correct method for hiding personal data, because drawing a black box is not enough.

Notes that others can act on

Markup someone else will read is different from a note to yourself. A highlighted paragraph leaves the reader asking what about it, while a one-sentence note noticeably reduces the number of rounds. Let colour carry meaning, for example yellow for attention, red for must change and green for approved, and explain the scheme in a note at the start.

A three-pass order for contract review

Following a set order rather than marking as you go speeds up a legal or commercial review and prevents omissions. First mark everything containing an amount, date or duration. Then mark the sentences that create obligations. Last, mark the wording you find unclear. That sweep is more reliable than reading end to end once.

Sharing the marked-up file

Because marks are written into the document, the recipient sees your notes in any viewer without special software. That does not mean they cannot be removed, and a clean version has to be regenerated from the original. Save the marked-up version under a new name and keep the original clean.

Download the marked-up PDF and send it by email. If you also need a signature use Sign PDF, and for text corrections use Edit PDF on the same document.

How it prints

A highlight that reads comfortably on screen can become a grey band over the text in black-and-white print. If the document will be printed, prefer light colours and put the important information in the note rather than the colour. In greyscale colours converge, so marks distinguished only by colour lose their meaning on paper.

Frequently Asked Questions

Can marks be removed?

In the file you download, the marks are written into the document. For a clean version you need to start again from the original, which is why keeping a clean copy matters.

Can I add notes to a PDF someone else marked up?

Yes. Layers added over the document accumulate, so you can add your own notes and download a new version.

Can I mark up a scanned document?

Yes. Because markup draws over the page, it works on scans too. If you want to draw neatly over lines of text, making the document searchable first makes it easier.

Do marks increase file size?

Drawings and notes are small vector objects, so the increase is negligible in most documents.

How do I write on or mark up a PDF?

Upload the PDF to the Markup tool, pick highlighter, pen, box, arrow or text and drag on the page. Click Apply and download to get the marked-up PDF. Everything runs in your browser.

Does highlighting over text erase it?

No. Marks are added on top and existing text is not removed. Highlighter and pen are semi-transparent, so the text below stays visible.

Can I undo or edit a mark I made?

Yes. Undo with Ctrl+Z, and use the Select tool to move, resize or recolour a mark afterwards.
