How to Convert PowerPoint to PDF (and Back)

Sharing a deck as a PDF keeps slides looking the same for everyone and safe from accidental edits. Here's how to convert PowerPoint to PDF — and back when you need to.

Sending a deck as a PowerPoint file can be risky: fonts may shift, animations may break, or slides may be changed by accident. PDF makes the deck look identical for everyone and un-editable.

Which one, when?

  • To share / present / archive: PowerPoint → PDF.
  • To edit an old deck / reuse content: PDF → PowerPoint.

What survives the conversion, and what doesn't

PDF is a fixed output format: it preserves how slides look but flattens everything interactive. Knowing this upfront avoids surprises after you send the deck.

  • Preserved: layout, colours, fonts, images, and the appearance of tables and charts.
  • Preserved: slide order and aspect ratio (16:9 or 4:3).
  • Lost: transitions and animations — an animated slide becomes one page in its final state.
  • Lost: embedded video and audio; only a poster image remains in place.
  • Changed: speaker notes are not included in the default output.

Why fonts shift, and how PDF fixes it

A PowerPoint file often does not embed the typeface; it only records its name. If the recipient does not have that font, the program substitutes something similar, lines shift and boxes overflow. In a PDF the fonts used are embedded in the document, so it looks the same wherever it is opened. If you will present from an unfamiliar computer, carrying a PDF copy is the safest route.

Practical settings for print and handouts

If you plan to hand the deck out, printing one slide per page usually wastes paper. After converting, use the page layout tool to place 2 or 4 slides on a sheet; it stays legible and costs less to print. On long decks this turns ten pages into three.

Realistic expectations going back to PowerPoint

The reverse conversion does not restore the original deck; a PDF does not contain the editable structure of slides. Each page becomes a slide and text boxes are rebuilt. That is enough to reuse text, copy headings or refresh an old deck, but if you expect to edit the original design precisely, finding the source file is far less work.

A last check before sending

  • Does content that appeared through animation show in the right state?
  • Is the small type in charts and tables readable?
  • Did hidden slides make it into the output — and do you want them there?
  • Does the file size fit the channel you are sharing through?

Frequently Asked Questions

Do animations work in a PDF?

They do not. A PDF is a fixed document, so an animated slide comes out as a single page in its completed state. If you need a step-by-step reveal, each step has to be its own slide.

Do speaker notes come across?

The default output contains slides only. To include notes, export from PowerPoint using the notes-page layout.

Is the 16:9 ratio preserved?

Yes. PDF pages are created at the slides' aspect ratio, so a 16:9 deck gives wide pages and a 4:3 deck gives squarer ones.

Can I convert a password-protected deck?

Files with an open password need the password removed first. Without it the conversion cannot run, which is the point of the protection rather than a limitation.

How do I convert PowerPoint to PDF?

Will the design break?

No. Slide layout, fonts and images are preserved; the deck looks the same on every device.

Can I convert the PDF back to PowerPoint?

Yes. Use the PDF to PowerPoint tool to turn each page into a slide in an editable .pptx file.
