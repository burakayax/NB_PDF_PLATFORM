Split a PDF: Extract Pages, Cut Sections or Save Every Page Separately

Often you need only the signature page or one section. Splitting gets you exactly that, and sending less is also a good privacy habit.

Sometimes the whole document is not what you need: the signature page of a contract, one section of a report, or a smaller part that fits an email. Splitting a PDF is built for that.

What people use it for

  • Extracting only the pages you need from a thick document.
  • Breaking one PDF into sections to share separately.
  • Cutting a large file into smaller parts for an email attachment.
  • Saving each page as its own PDF.

Three steps

  1. Open the PDF: Drop your file into the Split PDF tool. Pages are listed in a preview grid.
  2. Select pages or a range: Mark the pages you want. They can be combined into one PDF or saved as separate files.
  3. Download: Download the result as a single PDF, or as separate files inside a ZIP.

Split or delete?

If you want to keep just a few pages, splitting them out is the most practical. If you want to keep most pages and drop a few, Delete Pages is faster. Both run on your device.

  • To recombine parts into one file, use the Merge PDF tool.
  • If pages are out of order, fix them first with Organize pages.
  • Because it runs in your browser, your file is not sent over the internet.

Finding the pages you want

Locating where a section starts and ends can take longer than the split itself. If there is a contents page, read the range from there. If not and the document is searchable, search for a keyword. For scans, make the document searchable with OCR first, which is far more efficient than paging through it.

Share only what is needed

Sending the whole document is usually habit, not necessity. If someone asked for the signature page of a lease, one month of a statement or the financial section of a report, sending everything shares information nobody needed. It is also the right habit for personal data: give the other side enough to do their job, and no more.

Fitting a big file into an email

When a document exceeds the attachment limit you can compress or split. Compression works well on scans but is not always enough. Splitting into sensible parts and sending them in order is then the cleanest answer. Cut at section boundaries rather than arbitrarily, and name the files so the recipient can open them in sequence.

Naming the parts

  • Put the document name and page range in the file name, such as contract-p12-18.pdf.
  • Put the sequence at the end rather than the start so alphabetical sorting still works.
  • If you add a date, use year-month-day, which sorts correctly on its own.
  • State the number of parts, such as 1 of 3 and 2 of 3, so a missing part is noticed immediately.

Putting the parts back together

Splitting is reversible, because the parts can be merged back into one file. That helps if you want to work through a document section by section and combine it at the end. Check the order while merging; file names sort alphabetically, so naming them properly at the start pays off.

When splitting is not enough

If the information that must stay private sits inside a page, extracting that page does not help, because the information travels with the part. You then need to remove the page or permanently remove the area in question. A box drawn on top is not enough, since the text underneath stays in the file.

Frequently Asked Questions

Can I pick individual pages instead of a range?

Yes. You can mark scattered pages and gather them into one PDF, or take each as its own file.

Will the parts add up to more than the original file?

Usually slightly more, because each file carries its own structure. The difference is small and does not stop it solving an attachment-limit problem.

Do page numbers restart in each part?

If numbers are printed into the document, the original numbers stay, so a part starting at page 12 still shows 12. For fresh numbering you need to add it separately.

Can I split an encrypted document?

The content of an encrypted document cannot be read, so the password has to be removed first. If the parts will be shared under protection, add a password again when you are done.

How do I split a PDF?

Upload the file to the Split PDF tool, select the pages you want, and download them as a single PDF or separate files in a ZIP. The work happens in your browser.

Can I save each page as a separate PDF?

Yes. You can prepare the selected pages as separate files and download them inside a ZIP.

Is it free and private?

Yes. It is free, needs no signup, and your file never leaves your device.
