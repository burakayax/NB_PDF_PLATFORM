ATS-Friendly CV: 9 Practical Rules

Many companies run CVs through an applicant tracking system first. Nine practical rules to make sure it reads yours completely.

Many companies collect applications through an applicant tracking system (ATS). These systems read your CV and split the information into fields; anything they can't read, or place wrongly, looks incomplete on the recruiter's screen. A CV that looks beautiful but can't be read by a machine can be an invisible CV. These rules are practical ways to avoid that.

File and text

  1. Use a PDF that contains real text. Text in a CV saved as a screenshot or scanned image may not be read. If you can select text in the PDF with your mouse, you're on the right track.
  2. Don't bury information in images. Phone, email and skills should be text, not part of a logo or graphic.
  3. Choose standard fonts. Common, readable fonts are safest for people and systems alike; make sure Turkish characters (ş, ğ, ı, İ) display fully.

Structure and headings

  1. Use familiar headings: “Work Experience”, “Education”, “Skills”. Creative headings (“My Journey”) can stop a system recognising the section.
  2. Prefer a simple layout. Some systems read multi-column, table or boxed designs in the wrong order. If unsure, choose a single-column template.
  3. Write dates consistently, such as “Mar 2020 – Present”. Give every entry a title, company and date.

Content

  1. Use the ad's keywords naturally. If the ad says “project management” and you have that experience, use the same phrase — but never list a skill you don't have just to add a word.
  2. Spell out abbreviations once: “Customer Relationship Management (CRM)”. People and systems recognise both forms.
  3. Don't put key details in the page header or footer. Some systems skip those areas; place your contact details in the main body.

ATS behaviour varies from system to system and none guarantees a perfect read everywhere. The aim is to present information so that both people and machines read it easily.

A one-minute check before you send

  • Open the PDF, select all (Ctrl+A) and paste into a text editor: do the order and content make sense?
  • Are your phone and email written plainly in the header?
  • Is the file name clear, like first-last-cv.pdf?

Frequently Asked Questions

What is an ATS?

An applicant tracking system: software companies use to collect applications and extract information from CVs into a candidate list.

Does a photo break the ATS?

The image is usually ignored, but some systems struggle with CVs that include pictures. A simple single-column template with information written as text is the safest route.

Should I send Word or PDF?

Unless the ad asks for another format, a PDF with real text is a safe choice; it looks the same on every device.

Are the CVs from this tool ATS-ready?

The text in the PDF is selectable real text and reads in a single flow. Still, no tool can guarantee a result in a specific system.
